# Version 7.2.0 — 28 October 2026

Empty language notes, pattern headings and part grids are hidden; foundation cards are labeled as pronunciation foundations. The empty bordered note was not a progress bar.

Seven selected lexical entries (hale, kula, kumu, hele, hana, holoi, keiki) were checked against the named Pukui–Elbert (1986) entries at https://wehe.hilo.hawaii.edu/ on this date. The optional Words in context panel links each query and identifies the sense where needed. Search results also contain historical dictionaries and differently marked headwords; those are not substituted for the selected modern entries. This is a bounded vocabulary check, not a new independent audit of every sentence. Existing sentence references remain unchanged. No new Hawaiian example sentences were generated in this release.

Dictionary support appears in study or after checking an answer; hidden-recall also conceals it. Feedback identifies recognition, supported practice, correction retries and unaided written attempts. Round completion offers lesson selection and mixed review.

Validation: regression suite covers all 352 activities; browser traversal covers all 346 non-immersion activities at 390px, note/part visibility, answer concealment, correction feedback, retry scheduling, round completion and runtime errors. No changes to legacy olelo.html, storage identifiers, pull-to-refresh handling or existing curriculum sentences. Footer and asset URLs use 7.2.0. Hosting wrapper is pinned to the source commit.

Remaining limitations: no independent qualified Hawaiian educator audit; listening largely relies on external sources and self-report; no automated spoken-pronunciation assessment; learning effectiveness has not been measured with learners. Source traceability is not equivalent to teacher certification or demonstrated fluency outcomes.
